### Defects the casts were hiding

1. **Three receiving mutations appear non-functional in production.**
   `submit`/`cancel`/`reconcile_acquisition_receipt` are declared with UNNAMED
   SQL parameters. PostgREST resolves a JSON-body RPC by matching keys to
   parameter names, so it cannot call them; the generator omits all three while
   their named siblings are present. pgTAP does not catch it — those tests call
   the functions positionally in SQL and never traverse PostgREST. Recorded as
   **ESC-002**; repair needs a migration (`create or replace` cannot rename a
   parameter), which is database work outside this order.
2. **`list_acquisition_lines` is overloaded** — an 11-argument version *without*
   exclusion filtering still lives alongside the 12-argument one. Three other
   functions are also overloaded.
3. Four route-parameter/query paths fed `string | string[]` or unvalidated enum
   values into governed filters and mutations.
4. Four `.select()` column lists were built by string concatenation, which is
   not a literal type, so every row degraded to `GenericStringError`.
5. An embedded to-one relation was asserted to be an object while the
   relationship metadata describes an array — producing an empty lot map.

### Remaining exception manifest

`docs/ai/TYPE_ESCAPE_MANIFEST.md`. Three entries, each with file and symbol,
category, why generated types cannot express it, the narrowest cast, the
runtime validation protecting it, and a removal condition:

- **ESC-001** nullable RPC arguments (`asRpcArgs`) — PostgreSQL parameters are
  always nullable; the generator cannot say so.
- **ESC-002** the three uncallable receiving functions (`rpcNotInContract`,
  closed three-name union) — a database defect, not a typing limitation.
- **ESC-003** bigint minor units on the wire (`minorUnitArg`) — deferred to
  Work Order 7 rather than coerced into an unsafe number.

### Enforcement

`scripts/ci/escape-guard.mjs` detects new `as never`, broad `as any`, double
casts through `unknown`, untyped generic table names, and bypassed `.rpc()`
arguments or results. Two regimes: the four boundaries plus the shared contract
allow **zero** unregistered escapes; 53 files elsewhere are frozen at their
current count and may lose escapes but never gain one. A string-literal RPC name
through the typed client is deliberately not flagged.

`scripts/ci/type-negative.test.mjs` compiles seven cases in isolation and fails
if TypeScript **accepts** any of the six it must reject — unknown RPC name,
missing required argument, wrongly typed argument, invalid enum value, unknown
table, incompatible result assignment — with a positive control so none can pass
vacuously.
